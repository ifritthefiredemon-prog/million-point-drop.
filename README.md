# The Million Point Drop — Classroom Edition

A host-controlled, mobile-friendly quiz game for a classroom projector. Runs entirely in the browser; no server or account is required for gameplay.

## Features
- 10 editable questions, each with four answers, a correct answer, and optional explanation
- At least 3 teams, with the ability to add more
- Each team starts with 50 points (configurable for a new game)
- Host enters A/B/C/D allocations; all remaining points must be allocated
- Wrong-answer allocations are lost; correct-answer allocations are kept
- Countdown timer, synthesized sound effects, mute and volume controls
- Fullscreen mode, score screen, final rankings, print/save as PDF
- Questions are saved in this browser's local storage and can be exported/imported as JSON

## Run locally
Open `index.html` in a modern browser. Some browser settings may restrict local storage when opened as a file; hosting it on GitHub Pages is recommended.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new repository, for example `million-point-drop`.
2. Upload `index.html` to the repository root (the top-level folder). You may also upload this README.
3. Open the repository's **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the Pages deployment to finish. Your site will be at a URL similar to `https://YOUR-USERNAME.github.io/million-point-drop/`.
7. Open the link on the device you'll use to host the game. Use **Edit Questions** to enter your questions.

## Important notes
- Questions are saved in the browser on the device you use. They are not synced between devices. Export the question JSON as a backup.
- The sound effects are generated by the browser, so no external audio files are needed. Interact with the page first, because browsers block audio autoplay.
- The game is for virtual classroom points only. It does not process money or prizes.
